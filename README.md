# Global Travel Advisors — Cleaning Services

A responsive, static website for home, apartment and commercial cleaning services in the UAE.

## Deploy on Vercel

1. Import this GitHub repository into [Vercel](https://vercel.com/new).
2. Select **Other** as the framework preset if prompted.
3. Leave the build command and output directory blank; Vercel will serve `index.html` as a static site.
4. Deploy.

No database, build step, environment variables, or backend are required. The quote form opens a pre-filled email to `jagdishghimire07@gmail.com`; visitors can also call or WhatsApp **+971 56 693 9292**.

## Local preview

Open `index.html` directly in a browser, or run `npx serve .` from this folder.

Images and Google Fonts load from external providers.
